# Portfolio Website (Freelance ML Services)

A static, single-page portfolio/landing site for Akshay's freelance machine-learning services (forecasting, predictive analysis, segmentation, anomaly detection).

## Sections (from `index.html`)
Hero ("Custom Machine Learning Solutions"), Achievements, Services (Forecasting, Predictive Analysis, Segmentation, Anomaly Detection), Domains (Finance, Marketing, Manufacturing, Custom), Featured Work (Realtime Stock Analysis, Backorder Prediction System, Financial Analysis Platform, Telegram Referral Bot, Sentiment Analysis Tool), Skills and Technologies, and an FAQ.

## Tech stack
Plain HTML, CSS and vanilla JavaScript (`script.js`); no build step.

## Structure
```
index.html   styles.css   script.js
index copy.html          # older copy of the page
image/                   # project screenshots and icons
pikaso_embed.webp
```

## Run
Open `index.html` in a browser, or serve statically (`python -m http.server`). Can be hosted on GitHub Pages.

## Limitations
- The achievement figures and project cards are marketing copy, not verifiable from the repo.
- Stale duplicate `index copy.html`; no contact form backend or README originally.
